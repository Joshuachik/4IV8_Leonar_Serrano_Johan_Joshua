Objetivo del Portafolio

Presentar de manera formal y estructurada el conjunto de soluciones de software y prácticas web construidas durante el curso. Este espacio evidencia el proceso de aprendizaje continuo, la aplicación de reglas de diseño unificadas y el manejo progresivo de lógica computacional en el frontend y arquitecturas backend.

Elementos Aprendidos

  • Maquetación web estructurada bajo estándares semánticos de HTML5.
  • Aplicación de guías de estilo CSS personalizadas para interfaces responsivas y adaptables.
  • Estructuración de lógica interactiva y control del DOM con JavaScript nativo.
  • Diseño de sistemas dinámicos fundamentados en operaciones CRUD y persistencia lógica.
  • Implementación avanzada del patrón de arquitectura de software Modelo-Vista-Controlador (MVC) en Node.js.
